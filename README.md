# Engineering Practice

A collection of small experiments, exercises, and technical explorations related to my engineering path.

This is **not** my main project workspace. I use this folder to practice concepts, test ideas, regain programming muscle memory, and experiment with technologies before applying them to larger projects.

## Purpose

The goal is to keep learning practical without turning every small experiment into a full project.

I may create something here because I:

* Want to refresh a concept I haven't used in a while.
* Want to practice a programming language or technique.
* Want to test an idea before putting it into a real project.
* Want to experiment with hardware or embedded concepts.
* Want to quickly build a visual interface for a hardware experiment.
* Want to understand how a tool or technology works.

## Structure

```text
Practice/
│
├── C/
│   └── Small C exercises and concept refreshers
│
├── Embedded/
│   └── Microcontroller and embedded-system experiments
│
├── Web/
│   └── HTML/CSS/JavaScript experiments and simple interfaces
│
└── Electronics/
    └── Small electronics and circuit-related experiments
```

## Examples

Some things I might practice here:

* C pointers, structs, arrays, file handling, and memory.
* C modular programming and header files.
* GPIO, PWM, ADC, timers, interrupts, UART, I²C, and SPI.
* ESP32 experiments.
* Small Arduino experiments.
* HTML interfaces for hardware projects.
* Electronics calculations and circuit experiments.
* Quick tests with tools such as KiCad or other engineering software.

## Practice vs Projects

The distinction is simple:

**Practice** → "I want to learn or test something."

**Projects** → "I am building something."

A practice experiment can eventually become part of a real project, but it doesn't have to.

## Philosophy

> Learn the concept.
> Build something small.
> Break it.
> Understand why it broke.
> Apply what I learned to a real project.

Not everything here needs to be polished. Some files may be rough, incomplete, or exist only because I wanted to test one specific idea.

That's intentional.

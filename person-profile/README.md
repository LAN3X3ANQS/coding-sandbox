# Person Profile

A small C practice project for learning the fundamentals of `struct`.

## Objective

The goal of this project is to understand how a `struct` can be used to group related pieces of information into one custom data type.

## What I Am Practicing

- Defining a `struct`
- Creating a variable from a `struct`
- Accessing struct members using `.`
- Assigning values to struct members
- Printing struct members
- Understanding the difference between a struct definition and an actual struct variable

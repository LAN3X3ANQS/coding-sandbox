Python From Zero 🐍

A step-by-step path from print() to NumPy and Pandas.

Lesson 1 of 12

1. Your first Python program

Before variables, loops or libraries, you need to understand the basic idea: Python executes instructions from your code.

The print statement

print("Hello, world!")

Run it and Python displays:

Hello, world!
Think of print() as telling Python: “Put this information on the screen.”

Printing different things

print("Lanre") print(10) print(10 + 5) print("My score is", 90)
Try it

Write a program that prints your name, your age and the result of 20 + 22.

2. Values, strings and numbers

Python works with different kinds of values. Two important ones at this stage are text and numbers.

Strings

"Hello" "Lanre" "240211185"

Text is normally written inside quotation marks.

Numbers

10 # integer 3.14 # decimal / float 10 + 5 20 - 7 4 * 3 10 / 2
Notice that "10" and 10 are not the same thing. The first is text; the second is a number.

3. Variables

A variable gives a name to a value so you can use that value later.

x = 10 name = "Lanre" print(x) print(name)

= here means “assign this value to this variable.”

Changing a variable

score = 50 print(score) score = 80 print(score)
Practice

Create variables for your name, age and a favourite number. Print all three.

4. Lists

A list stores multiple values in one ordered collection.

numbers = [10, 20, 30, 40] print(numbers) print(numbers[0]) print(numbers[2])
Python starts counting list positions from 0. So numbers[0] is 10.

Changing a list

numbers.append(50) numbers.remove(20) print(numbers)

5. Loops

A loop lets you repeat an operation without writing the same instruction over and over.

numbers = [10, 20, 30, 40] for number in numbers: print(number)

Read this as: “For each number inside numbers, print the number.”

Another example

names = ["Ada", "John", "Mary"] for name in names: print("Hello", name)

6. Conditions

Conditions allow your program to make decisions.

x = 10 if x > 5: print("Greater than 5")

Comparisons

x == 10 # equal to x != 10 # not equal x > 5 x < 5 x >= 5 x <= 5

if / else

age = 20 if age >= 18: print("Adult") else: print("Under 18")

7. Functions

A function is a reusable block of code designed to perform a particular task.

def add(a, b): return a + b result = add(3, 4) print(result)

a and b are parameters. return sends a result back.

Functions become especially useful when your programs get larger: instead of putting everything inside one giant block, you divide the program into logical pieces.

8. Dictionaries

A dictionary stores information as key-value pairs.

student = { "name": "John", "age": 20 } print(student["name"]) print(student["age"])

Why this is useful

A student has several pieces of information. Instead of remembering that position 0 means a name and position 1 means age, the dictionary lets you ask for the value by its key.

student["score"] = 85 print(student)

9. Putting the basics together

Now combine variables, lists, loops, conditions, functions and dictionaries into a small program.

students = [ {"name": "Ada", "score": 85}, {"name": "John", "score": 62}, {"name": "Mary", "score": 91} ] def passed(score): return score >= 50 for student in students: if passed(student["score"]): print(student["name"], "passed") else: print(student["name"], "failed")
This is the point where the individual concepts begin to become programming rather than isolated syntax.

10. Importing libraries

Python's standard language is powerful, but libraries give you extra tools written by other developers.

import numpy as np import pandas as pd

as np and as pd create shorter names for the libraries.

Using the imported library

import numpy as np data = np.array([1, 2, 3, 4]) print(data)

11. NumPy basics

NumPy is a major Python library for numerical computing. Its central object is the array.

import numpy as np data = np.array([1, 2, 3, 4]) print(data) print(data + 10) print(data * 2) print(data.mean())
The important idea is not just the syntax. NumPy lets you work efficiently with collections of numbers and perform mathematical operations on them.

Array shape

data = np.array([1, 2, 3, 4]) print(data.shape)

12. Pandas basics

Pandas is designed for working with structured data such as tables.

import pandas as pd df = pd.DataFrame({ "Name": ["A", "B", "C"], "Score": [70, 80, 90] }) print(df)

Working with columns

print(df["Name"]) print(df["Score"]) print(df["Score"].mean())

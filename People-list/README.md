# People List

A small C practice project for learning how to store multiple `struct` records in an array.

## Objective

The goal of this project is to understand how an array of structs can be used to store information about multiple people.

## What I Am Practicing

- Defining a `struct`
- Creating an array of structs
- Accessing struct members with `.`
- Initializing multiple struct records
- Using a `for` loop to process multiple records
